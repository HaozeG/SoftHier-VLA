# SoftHier-VLA

This repo is for exploration on mapping VLA applications for physical AI to tile-based many-PE chip like [SoftHier](https://github.com/gvsoc/gvsoc/tree/soft_hier_release).

**Start here:** [docs/research-plan/README.md](docs/research-plan/README.md): problem statement, research questions, roadmap and reading order.

## Repository layout

| path | content |
| --- | --- |
| `softhier_vla_wiki/` | git submodule: the project wiki (knowledge notes, glossary, project decisions) |
| `docs/designs/` | design documents |
| `docs/research-plan/` | research plan: problem statement, one file per research question, working material |
| `docs/analysis/` | analysis pages: conventions, hardware parameters, stage totals and cross-check (some generated by `infra/workload-modeling/`) |
| `third_party/` | external code used as submodules, such as the GVSoC simulator (`soft_hier_release` branch) |
| `third_party/softhier-kernels/` | git submodule: kernel source, the hand-written SoftHier kernels (`implementation/` of `HaozeG/gvsoc`, branch `gelu-layernorm-kernels`); see `infra/kernel-runs/README.md` |
| `infra/` | reusable parts: environment scripts, simulator build and tests, golden reference, LIBERO evaluation, workload model (`infra/workload-modeling/`) |
| `experiments/<name>/` | one experiment: its compiler checkout, arch file, configs, patches and records; present only on that experiment's branch |

Layout rule: parts that later experiments reuse (simulator, golden reference, LIBERO evaluation, environment scripts, workload model) live on `main` under `third_party/` and `infra/`. Everything specific to one experiment lives under `experiments/<name>/` on that experiment's branch.

## Tracked metrics

The first baseline (SmolVLA) tracks two metrics:

*   **Latency:** the time of one policy call on SoftHier, from the GVSoC simulator.
*   **Success rate:** closed-loop task success on the LIBERO benchmark, measured on GPU.

Decision: [first baseline](softhier_vla_wiki/memories/decisions/2026-11-10-first-baseline-latency-and-success-rate.md) (in the wiki submodule). Design: [docs/designs/smolvla-softhier-baseline.md](docs/designs/smolvla-softhier-baseline.md).
