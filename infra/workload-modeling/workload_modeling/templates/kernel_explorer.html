SmolVLA on SoftHier H1: kernel mapping explorer

Stage-1 baseline, vlabench-3cam, one policy call composed from hand-written kernels simulated one at a time (GVSoC, DRAMSys HBM). W1 and W1-b are deployed with upstream's whole-graph HBM plan and kernel-selection rule (constants.yaml h1_plan, h1_plan_w1b); the comparison on each is the plan-constrained sweep of the same plan (h1_psweep, h1_psweep_w1b). Every time comes from a run under the plan. Companion to docs/analysis/kernel-mapping-h1.md.

Plans

Each plan is one set of run results: its own operator split, run keys, kernel settings and times, loaded as a whole. Pick up to two to see side by side (a third pick replaces the older one); each column has its own tables, sorting, kernel detail and mesh, nothing is aligned between them, so plans that split or map operators differently compare as they are. Every time is a sum of measured kernel times under the plan's deployment (estimate, no overlap).
