Where the time goes, per stage (estimate)

Each matrix kernel's time is split into ideal (true FLOP at the 131.1 TFLOP/s peak), padding (padded FLOP at the same rate: shape padding to whole tiles, plus for GEMM RedMulE array padding to whole 32 x 64 output blocks), idle clusters (padded FLOP on only the clusters the mapping uses), HBM floor (extra time if the operator's unique bytes need longer at 1,024 GB/s; that bandwidth is an inference, the memspec gives half) and rest beyond roofline (tiling re-reads, NoC, synchronisation, per-call overhead, HBM below peak). Row operators run on the vector cores and count whole. MFU = ideal / total.
